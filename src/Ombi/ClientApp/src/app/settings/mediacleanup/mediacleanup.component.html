Media Cleanup

Media Cleanup has two independent systems. User permissions still apply in addition to these server-wide settings.

Allow users to remove their own requests

Own request removal Off Request removal Immediate deletion

Request removal sends the item to a cleanup manager for approval. Immediate deletion lets appropriately-permitted users remove only media they originally requested. A TV series counts as an own request only when all Ombi child requests for that series belong to the same user.

Community cleanup voting

Community cleanup Off Admin approval Automatic after threshold

Admin approval turns a successful vote into a review item. Automatic mode schedules removal as soon as the threshold is met, then waits for the grace period before deleting.

Minimum Remove votes Required Remove vote lead Voting period (days) Grace period (days) Minimum media age (days)

After voting ends, Remove votes must meet the minimum and lead Keep votes by at least the configured amount. For example, a required lead of 1 means 6 Remove / 5 Keep passes; it does not mean one Keep vote blocks removal.

Any Keep vote prevents removal

When enabled, one or more Keep votes makes the community cleanup vote fail regardless of how many Remove votes were cast. The minimum Remove vote requirement still applies when there are no Keep votes.

Restrict cleanup nominations to requesters and Keep voters

When enabled, users can start a community cleanup vote for media they requested or media for which they have cleanup stewardship from a previous Keep vote in a community cleanup that ended with the media being kept. Voting Keep grants stewardship so the user can nominate the title later when they are finished with it; a later Delete vote in another kept cleanup gives that stewardship up. Administrators, Power Users, and users with ManageMediaCleanup can still nominate any eligible media. Users can still vote on nominations started by other users.

Original requester Keep vote always vetoes removal

When enabled, a Keep vote from any original requester blocks removal even if other Keep votes would not. This is redundant when “Any Keep vote prevents removal” is enabled.

Approval notifications

Email cleanup managers when an item needs approval

When Ombi email notifications are enabled, Admin, PowerUser, and ManageMediaCleanup users with an email address receive an email when an own-removal request or a successful community vote enters the approval queue.

Voting reminder emails

Email users a digest of cleanup votes they have not answered

The reminder runs on the Media Cleanup Vote Reminder schedule under Scheduled Tasks. Each eligible voter receives one digest containing only active community votes they have not voted on yet. The default schedule is weekly on Monday at 9:00 AM.

Deletion behavior

Delete media files in Radarr/Sonarr

Warning: enabling this makes a completed cleanup destructive. Radarr/Sonarr will be asked to permanently delete the files.

Add import exclusion after deletion

Prevents the deleted movie/series from being immediately re-imported by the *arr application. Ombi removes its request record after successful cleanup, so users can submit a new Ombi request later.

Required roles

Assign RequestMediaRemoval, DeleteOwnMedia, VoteOnMediaCleanup, and/or ManageMediaCleanup under User Management as appropriate. Admin and PowerUser accounts are treated as cleanup managers.
